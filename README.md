# 🚀 Projects

## 📌 Loan Risk Analysis & Loan Approval Prediction
An end-to-end analytics solution combining **Power BI** and **Machine Learning** to analyze loan applications, evaluate applicant financial strength, identify risk patterns, and predict loan approval using a **Random Forest Classifier**.

### Key Highlights
- Developed a multi-page interactive Power BI dashboard for loan risk analysis.
- Analyzed applicant income, loan amount, CIBIL score, assets, and approval trends.
- Built a Random Forest model achieving **97.78% prediction accuracy**.
- Identified key factors influencing loan approval using feature importance analysis.
- Predicted loan approvals for **150 new applicants** using a saved machine learning model.

**Tools & Technologies**

Power BI • Python • Pandas • NumPy • Scikit-learn • Joblib • Power Query
